## Критерии оценки

**100 баллов за приложение + 5 за README. Итоговая оценка — не больше 100 баллов после вычета штрафов.**

Баллы по каждому пункту начисляются за полное выполнение соответствующих требований к реализации. Все спорные моменты решаются в пользу студента.

### Генерация разметки — 15 баллов

- [x] **15 баллов:** интерфейс создан через `document.createElement` или собственные обёртки над ним. В исходном `<body>` есть только `<script>`.

### Начало игры — 10 баллов

- [x] **5 баллов:** на поле 16 карточек — 8 пар, закрытых одинаковой рубашкой.
- [x] **5 баллов:** игра начинается автоматически при загрузке и перезагрузке страницы. Счётчики обнулены, кнопки хедера доступны.

### Перемешивание — 5 баллов

- [x] **5 баллов:** карточки случайно перемешиваются при загрузке страницы и каждой новой игре.

### Выбор карточек — 15 баллов

- [x] **5 баллов:** можно открыть две карточки по очереди; первая ждёт выбора второй.
- [x] **5 баллов:** совпавшая пара остаётся открытой, игра продолжается.
- [x] **5 баллов:** повторные клики по открытым карточкам и найденным парам игнорируются.

### Несовпавшие пары — 10 баллов

- [x] **5 баллов:** несовпавшая пара закрывается через 700–1500 мс, в том числе при открытой таблице лидеров.
- [x] **5 баллов:** до закрытия пары другие карточки выбрать нельзя.

### Счётчики — 5 баллов

- [x] **5 баллов:** ходы и найденные пары подсчитываются по правилам игры.

### Модальные окна — 15 баллов

- [x] **5 баллов:** после нахождения всех пар открывается модальное окно победы с итоговым числом ходов.
- [x] **5 баллов:** оба модальных окна открываются и закрываются по общим правилам; общий код переиспользуется.
- [x] **5 баллов:** просмотр и закрытие модальных окон не сбрасывают поле и счётчики.

### Таблица лидеров — 10 баллов

- [x] **5 баллов:** кнопка в хедере открывает модальное окно с корректно оформленным и отсортированным топ-10 или сообщением об отсутствии результатов.
- [x] **5 баллов:** завершённые игры сохраняются в `localStorage` без дубликатов; результаты доступны после повторного открытия приложения.

### Новая игра — 15 баллов

- [x] **10 баллов:** обе кнопки «Новая игра» сбрасывают поле и счётчики без перезагрузки страницы; модальное окно победы закрывается.
- [x] **5 баллов:** перезапуск с открытой несовпавшей парой происходит сразу и отменяет её таймер.
