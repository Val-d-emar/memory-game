# Memory Game

Классическая игра на поиск совпадений пар игральных карт, реализованная на чистом нативном JavaScript в рамках курса RS School [JS / Front-end Course](https://rs.school/ru/courses/javascript).

## 🎮 Правила и особенности игры

- **Игровое поле:** 16 карт (8 пар). В начале игры все карты закрыты одинаковой рубашкой и перемешаны по алгоритму Фишера — Йейтса (Fisher–Yates shuffle).
- **Счётчики:**
  - _Ходы:_ ход засчитывается в момент открытия второй карточки независимо от результата.
  - _Пары:_ отображается количество найденных пар (от 0 до 8).
- **Механика выбора:**
  - При несовпадении пары карточки остаются открытыми 1 секунду, после чего закрываются. В это время клики по другим картам заблокированы.
  - Повторные клики по открытым картам или найденным парам игнорируются.
- **Модальные окна:**
  - Реализованы на нативном теге `<dialog>` с единым переиспользуемым компонентом оболочки.
  - Поддерживают закрытие по кнопке «Закрыть», клику по затемнённому фону (backdrop) и клавише Escape.
  - Блокируют скролл страницы при открытии.
- **Таблица лидеров:**
  - Сохраняет до 10 лучших результатов в `localStorage`.
  - Сортировка: меньше ходов — выше место; при равных ходах выше более ранняя игра.
  - Дата фиксируется строго в формате `ДД.ММ.ГГГГ`.
- **Перезапуск:**
  - Кнопка «Новая игра» в хедере и в окне победы мгновенно сбрасывает поле, отменяет активный таймер несовпадения и перемешивает колоду заново.

## 🛠 Технологический стек и безопасность

- **JavaScript (ES2022 / ES Modules):** 100% чистый нативный DOM.
- **Безопасность разметки:** Весь интерфейс динамически генерируется через `document.createElement`, `classList`, `setAttribute` и `append`. Строго соблюдён запрет на `innerHTML`, `outerHTML`, `insertAdjacentHTML` и сторонние UI-фреймворки.
- **Тег `<body>`** в исходном `index.html` содержит строго один тег `<script>`.
- **SCSS:** стилизация, CSS Grid 4x4, плавная 3D-анимация переворота карт (`transform-style: preserve-3d`).
- **Сборщик:** Vite.
- **Инструменты контроля качества:** Prettier, Stylelint, Husky, lint-staged.
- **Графика:** Векторный набор игральных карт под свободной лицензией CC0 (Public Domain).

## 🚀 Инструкция по локальному запуску

1. **Клонируйте репозиторий:**

   ```bash
   git clone -b memory-game https://github.com/Val-d-emar/memory-game.git
   cd memory-game
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Запустите сервер разработки:**

   ```bash
   npm run dev
   ```

   Откройте появившийся локальный адрес (обычно `http://localhost:5173`) в браузере.

4. **Сборка продакшн-версии и предпросмотр:**

   ```bash
   npm run build
   npm run preview
   ```

5. **Проверка стилей и форматирование кода:**

   ```bash
   npm run lint:style
   npm run format
   ```
